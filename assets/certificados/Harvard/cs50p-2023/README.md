# CS50's Introduction to Programming with Python

## Resumo

Curso da trilha `CS50`, concluído em `2023`, com foco em fundamentos de programação com `Python`.

O certificado local confirma a conclusão de `nine problem sets` e `one final project`. Com base na estimativa oficial de `10 semanas` e `3 a 9 horas por semana`, a carga total média estimada fica em `60 horas`.

## Conteúdo

De forma objetiva, o curso cobre:

- variáveis e funções
- condicionais e estruturas de repetição
- exceções e bibliotecas
- testes
- manipulação de arquivos
- expressões regulares
- orientação a objetos

## Meu Parecer

Curso forte para consolidar base de programação em Python com prática real. A exigência de problem sets e projeto final dá um peso maior do que cursos apenas expositivos.
